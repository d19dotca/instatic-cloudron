# Instatic

Instatic is an open-source visual CMS that publishes semantic, plain HTML and clean CSS. The public site is served from generated static artifacts, while authors manage content and design through the protected `/admin` interface.

This Cloudron Community App package provides managed PostgreSQL, persistent media and published artifacts, automatic encryption-secret generation, health monitoring, backups, restore compatibility, and restart-safe configuration. CMS-native forms persist submissions in Instatic data tables; upstream Instatic `0.0.17` does not send form-submission email notifications.

Instatic is an early-stage upstream project. Review the package changelog and take a backup before every update.
